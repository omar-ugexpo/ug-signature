# ug-signature

Images and page for the United Group email signature (Eng. Omar Mohamed).

- `index.html`: the signature with a "Copy signature" button
- `signature.html`: the signature as plain HTML, for pasting into an email client
- `img/`: logos and icons used by the signature (must stay public so recipients see them)

Do not rename or delete files in `img/`, or logos will disappear from sent emails.
